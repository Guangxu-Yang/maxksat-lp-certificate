## 从这次提升学到什么

完整数值 LP 最终由低阶 `d1` 和 `d2` 同时卡住：分别约为 `0.7426948156744636` 与 `0.7426948156744602`。fine-unary 高阶自由度被完整吸收；精确 H3/H4/H5 upper slack 等于人为加入的 `1e-12` 修复余量，不能据此说高阶是下一步瓶颈。

因此下一轮最应优先改变的是外层 rounding 曲线、非均匀 bucket boundary 和 `w2:w1` 比例，并用完整 joint d1/d2 筛选。只增加高阶变量、只看 d1 上界或只追 GPU 利用率，都不直接对应当前严格瓶颈。
